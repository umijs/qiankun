# lifecycle-missing：生命周期导出不完整

## 触发原因

qiankun 未能从微应用入口取得完整的生命周期对象。入口的命名导出、默认导出、沙箱最后写入的全局属性，以及以应用名称命名的全局属性，均未同时提供 `bootstrap`、`mount` 和 `unmount` 三个函数。

## 排查步骤

1. 检查控制台中更早出现的错误，确认入口脚本已完成加载和执行。
2. 检查部署后的入口文件，确认生命周期函数确实出现在构建产物的导出中。
3. 检查三个字段的实际类型。当前校验要求每个字段都是函数，缺失字段或函数数组均不能通过校验。

## 解决办法

ESM 入口可以分别导出三个生命周期函数，也可以默认导出包含这三个函数的对象。经典脚本入口应通过构建工具的库导出配置，将完整生命周期对象暴露给沙箱。修正导出后重新构建并部署微应用；仅在源码中声明函数而未导出，不能满足此要求。
