# module-context-missing：模块加载上下文丢失

## 触发原因

动态导入的运行时桥传入了一个上下文标识，但当前实例没有登记对应的模块加载上下文。正常生成的运行时代码应引用本实例已登记的上下文。

错误信息中的 `credentials context` 指模块加载的内部上下文，不能据此认定是登录状态或 cookie 配置错误。

## 排查步骤

1. 保留完整错误信息、调用栈、模块 URL 和 qiankun 版本。
2. 检查运行时生成的模块是否被手工修改，或从另一个实例复制而来。
3. 检查预编译与加载流程是否通过公开 API 传递产物，避免复用带有实例私有标识的运行时代码。

## 解决办法

若使用了修改过或跨实例复制的运行时代码，应从原始源码重新生成产物，并通过当前实例的公开接口加载。

若未修改内部产物且仍可复现，请提交 qiankun 问题报告，附上最小模块源码、加载方式、版本和完整调用栈。此错误涉及内部上下文约束，无法保证通过调整某项业务配置解决。
