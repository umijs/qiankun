# entry-duplicate：入口脚本重复

## 触发原因

同一 HTML 入口中有多个被 qiankun 识别为入口的外部脚本。加载器遇到第二个带有 `entry` 属性的外部脚本时，会抛出此错误。

## 排查步骤

1. 在网络面板中查看服务器实际返回的 HTML，查找带有 `entry` 属性的外部脚本。
2. 核对构建插件配置，检查手工标记与插件生成的标记是否重复。
3. 区分应用入口、运行时代码和公共依赖脚本，确认哪个脚本负责导出生命周期函数。

## 解决办法

只为真正的应用入口保留 `entry` 属性。其他脚本仍可保留，但不应重复标记为入口。若由构建插件生成标记，应在插件配置或 HTML 模板中修正，避免下次构建重新生成重复标记。
